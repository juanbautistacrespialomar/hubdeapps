Administrar trastienda (solo vos)

Editá el JSON de tus apps privadas, poné el PIN con el que las querés cifrar y generá el código. Después pegá ese texto reemplazando el valor de HIDDEN_ENCRYPTED en el archivo index.html. El campo logo admite un data-URI o directamente una URL a una imagen.

¿No sabés cómo instalar la app?

Seguí este instructivo según tu teléfono y navegador.

📱 Android (con Chrome)

  1. Abrí el link en Chrome.
  2. Tocá el menú de los tres puntitos (⋮) arriba a la derecha.
  3. Elegí "Instalar app" (o "Agregar a pantalla de inicio").
  4. Confirmá con Instalar.

🍎 iPhone (con Chrome)

  1. Abrí el link en Chrome.
  2. Tocá el botón Compartir (el cuadradito con la flecha ⬆️).
  3. Tocá "Ver más" si hace falta, y elegí "Añadir a pantalla de inicio".
  4. Tocá Agregar.

🍎 iPhone (con Safari) — alternativa

  1. Abrí el link en Safari.
  2. Tocá Compartir (⬆️, abajo en el centro).
  3. Deslizá y tocá "Agregar a inicio".
  4. Tocá Agregar.
